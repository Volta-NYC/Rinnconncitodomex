## 域名常见问题解答

### 什么是域名，为什么我需要一个域名？

用户通过在浏览器中键入域名来查找网站，这类似于您使用街道地址查找建筑物。每个连接到互联网的网站、服务器或数字设备都分配了一个 IP 地址，您可以使用该地址进行查看或访问。这种 IP 地址是一长串数字和字母，人们很难记住，因此域名只是该 IP 地址的一个用户友好的版本。

当您在浏览器中键入域名（如 www.godaddy.com 或 www.google.com），域名系统（或 DNS）会获取此域名，然后将其转换为 IP 地址，从而可以找到相关联的网站。

拥有专属域名有助于让在线搜索您或您的业务的人知道您的公司是一家合法经营的公司。借助域名，您可以实现以下目标：

- 想经营店面或电子商务生意？不妨 [创建网站](https://www.godaddy.com/zh-sg/websites/website-builder)
- 使用您的域名 [创建专业邮箱](https://www.godaddy.com/zh-sg/email/professional-business-email)

作为全球领先注册商，GoDaddy 可以帮您找到适合您需求的理想域名。您可以使用页面顶部的搜索工具来查询域名是否可用，或者使用 [GoDaddy Airo](https://www.godaddy.com/zh-sg/airo) 将您的创意发布上线。无论您处于哪个阶段，我们都能助您打造并壮大在线形象。从包含免费 SSL 证书的 [虚拟主机服务](https://www.godaddy.com/zh-sg/hosting/web-hosting)，到能帮您确立品牌形象的 AI [徽标生成器](https://www.godaddy.com/zh-sg/logo-maker)，再到助您轻松管理社交媒体、SEO 等事务的 [数字营销套件](https://www.godaddy.com/zh-sg/online-marketing/digital-marketing)，我们一应俱全。此外，我们的客户支持团队会为全部产品和服务提供专业的金牌技术支持。

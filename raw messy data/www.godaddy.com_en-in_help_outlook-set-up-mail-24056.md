# Outlook: Set up mail

Now that your Business Email account is ready, let's set up your email in Outlook. Choose the version below that you want to use. You can [find out which version of Outlook you have](https://support.office.com/en-us/article/What-version-of-Office-am-I-using-932788b8-a3ce-44bf-bb09-e334518b8b19), if you don't know.

**Note:** Outlook 2007 is **not supported**. Please [update your version of Outlook](https://technet.microsoft.com/library/dn803988%28v=office.14%29.aspx) before proceeding.

### El dominio para empresas en Australia.

El dominio net.au es para empresas comerciales y propietarios de marcas o solicitantes australianos, y tiene la misma credibilidad global que un .com. Este dominio es la mejor opción para empresas con sede en Australia y empresas internacionales con productos para ofrecer a Australia. Si tu empresa .com.au tiene una rama técnica, puedes registrar un dominio net.au para esa división. Pero no es solo para las empresas de TI, **.net.au** es para cualquier tipo de empresa.

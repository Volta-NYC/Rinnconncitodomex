### What is an API?

An API, or Application Programming Interface, is a set of rules and protocols that allow different programs to communicate and share information with each other. GoDaddy APIs offer a way to access domain-related services and functions, such as searching for domains or managing DNS settings.

### Why would I need to use an API?

Access to GoDaddy domain-related APIs gives you the flexibility to interact with domain information at a large scale. These APIs help you build a custom interface, improving efficiency and keeping data secure when managing domain details without having to develop your own applications.

### What domain APIs are available?

There are multiple APIs available to help you manage domain details and functions.

- [**Aftermarket**](https://developer.godaddy.com/doc/endpoint/aftermarket): Remove listings and add expiry listings
- [**Auctions**](https://developer.godaddy.com/doc/endpoint/auctions): Place multiple auction bids
- [**Domains**](https://developer.godaddy.com/doc/endpoint/domains): Retrieve and manage domain information
- [**Parking**](https://developer.godaddy.com/doc/endpoint/parking): Retrieve parking and domain metrics
- [**Valuation**](https://api.frontdoor.godaddy.com/v1/domains/govalues/api-doc/): Perform domain valuations

### How do I access an API?

Get all the details for accessing and using GoDaddy APIs in our handy [**Get Started** documentation](https://developer.godaddy.com/getstarted). All GoDaddy APIs are free to access and use. Domain-related APIs have usage limits to protect against abuse and ensure the availability of our systems.

- Customers with at least one active domain in their account get access to the Domains API with a monthly usage limit of 20,000 API calls.
- Customers with 50 or more domains active in their account get access to the Domains API and domain availability checks with a monthly usage limit of 20,000 API calls.
- Customers who spend a monthly average of at least US$20 (or equivalent in local currency) get access to the Domains API and domain availability checks with a monthly usage limit of 20,000 API calls.

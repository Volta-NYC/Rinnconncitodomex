## 網域評估常見問題

### 如何才算是好網域？

簡單回答您：影響因素有很多。這個網域好記嗎？是只有一個字，還是由十多個字組成的呢？是不是流行語？這些因素還只是一部分而已。

### 什麼是網域評估？

GoDaddy 網域評估使用機器學習技術，可以正確預估網域名稱價值。我們使用大量資料以及文字記號化技術，發展出可以評估網域價值的模組。簡單來說，網域估價工具在預測您的網域價值時，可以排除許多的不確定因素。因為我們的網域評估會準確抓取網域中含有的字串，所以您選取網域名稱時，考慮加入重要 SEO 字彙就是關鍵之處。

### GoDaddy 可以評估其他註冊商的網域嗎？

GoDaddy 可以評估任何註冊商的網域名稱，不過我們對一般常見英文網域提供的估價會比較準確。

### GoDaddy 能評估我擁有的所有網域嗎？

沒錯，GoDaddy 終有一日會有足夠資源，屆時就能評估所有提供網域。如果您擁有具有價值的網域名稱，值得續約或保護的話，我們會透過「我的網域」和您的 GoDaddy 帳戶發送通知。

### GoDaddy 能為已有內容的網站評估網域嗎？

GoDaddy 無法評估已有內容的網站，但是可以提供網域評估工具，無論網域內已有什麼網站都可以使用。簡單來說，我們不會將已開發完成的網站納入考量，只會預估網址的售價。我們會比較該網域和其他網域過去販售的價值，其中並不含已開發網站的售價。

### GoDaddy 網域 API 方案提供哪些資料？

GoDaddy 網域 API 提供多種強大功能，可提升使用者管理和使用網域名稱的效率。

1. **網域搜尋和購買**：使用者可以搜尋網域是否可供選購，並註冊網域。支援大量搜尋、聯絡人驗證，並可用綱要搜尋功能篩選特定頂級網域。
2. **網域管理**：API 可更新網域詳細資訊，如 DNS 記錄、聯絡人和隱私保護設定。使用者能夠取消網域、續約網域，以及在不同註冊商之間轉移網域，包括處理轉移要求。
3. **DNS 記錄**：可根據網域類型和名稱啟用 DNS 記錄搜尋、新增、修改和刪除功能。
4. **網域評估**：使用者可以評估網域名稱，並瞭解建議刊登價格，以及出售機率。

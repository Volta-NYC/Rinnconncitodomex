## Запитання та відповіді щодо ресурсу "Оцінювання доменів"

### Якими є характеристики ідеального домену?

Якщо коротко, їх багато. Чи легко воно запам’ятовується? Зі скількох слів воно складається? Чи популярне це слово або словосполучення? Це лише кілька факторів.

### Що таке оцінювання доменів?

Оцінювання доменів компанії GoDaddy використовує машинне навчання для точного прогнозування вартості доменного імені. Використовуючи великі об’єми даних і виділяючи основні слова, ми створили модель, яка здатна оцінити вартість домену. Простіше кажучи, інструмент оцінювання домену усуває багато домислів, коли йдеться про прогнозування вартості вашого домену. Оскільки наше оцінювання домену найбільш ефективне тоді, коли стоїть акцент на точному виборі слів для домену, важливо враховувати включення основних термінів SEO під час вибору доменного імені.

### Чи може компанія GoDaddy оцінювати домени, що належать іншим реєстраторам?

GoDaddy може оцінювати доменні імена будь-якого реєстратора, але найточніші результати матимуть звичайні домени англійською мовою.

### Чи оцінюватиме компанія GoDaddy моє повне портфоліо доменів?

Так, у перспективі компанія GoDaddy матиме ресурси для оцінки повних портфоліо доменів. Якщо у вас з’явиться цінне доменне ім’я, яке слід поновити або захистити, ми повідомимо вас через послугу "Мої домени" і ваш обліковий запис GoDaddy.

### Чи здійснює компанія GoDaddy оцінювання доменів для розроблених вебсайтів?

GoDaddy не оцінює розроблені вебсайти, але ми можемо оцінити будь-який домен незалежно від того, які вебсайти належать до нього. Якщо коротко, ми не враховуємо розроблені веб-сайти, а лише прогнозуємо ціну URL-адреси для продажу. Для цього ми порівнюємо цінність домену з іншими доменами з архіву продажу, де ціна продажу не включає продаж розроблених веб-сайтів.

### Які дані включено до планів API для доменів компанії GoDaddy?

API для доменів компанії GoDaddy забезпечує набір корисних функцій, що дають змогу користувачам ефективно керувати доменними іменами й взаємодіяти з ними.

1. **Пошук і купівля доменів**: користувачі можуть шукати доступні домени та здійснювати їх реєстрацію. Він підтримує масовий пошук, перевірку контактів і пошук схем для конкретних доменів верхнього рівня.
2. **Керування доменом**: API дає змогу оновлювати дані домену, як-от записи DNS, контакти й настройки конфіденційності. Крім того, користувачі можуть скасовувати домени, поновлювати їх і передавати між реєстраторами, здійснюючи обробку запитів на передачу.
3. **Записи DNS**: API дає змогу отримувати, додавати, змінювати та видаляти записи DNS на основі типу й імені домену.
4. **Оцінка домену**: користувачі можуть оцінити доменні імена й отримати запропоновані прайс-лист і можливість продажу.

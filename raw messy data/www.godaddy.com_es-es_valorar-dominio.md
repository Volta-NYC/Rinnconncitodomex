## Preguntas frecuentes sobre Valoración de dominios

### ¿Qué hace que un nombre de dominio sea bueno?

En realidad hay muchos factores que tener en cuenta. ¿Es fácil de recordar? ¿Se compone de una palabra o de doce? ¿Es una palabra o frase popular? Y eso son solo algunos factores.

### ¿Qué es la valoración de dominios?

Las valoraciones de dominios de GoDaddy utilizan aprendizaje automático para predecir el valor del nombre de dominio. Utilizando grandes cantidades de datos y analizando palabras, hemos desarrollado un modelo para evaluar dominios. Simplificando, la herramienta de valoración de dominios reduce en gran medida las suposiciones para predecir el valor de un dominio. Dado que la forma más eficaz de realizar la valoración de dominios es centrándote en las palabras, es importante considerar incluir términos SEO pivotantes al eligir el nombre.

### ¿GoDaddy valora dominios de otros registradores?

GoDaddy puede valorar nombres de dominio de cualquier registrador, pero logramos el mayor nivel de precisión con nombres comunes en inglés.

### ¿GoDaddy valorará toda mi cartera de dominios?

Sí, GoDaddy dispondrá de los recursos necesarios para valorar todas las carteras de dominios. Cuando tengas un nombre de dominio valioso que quieras renovar o proteger, te informaremos mediante Mis dominios y en tu cuenta de GoDaddy.

### ¿GoDaddy proporciona valoraciones de dominio para web desarrolladas?

GoDaddy no valora webs desarrolladas, pero podemos proporcionar una valoración de cualquier dominio, independientemente de si tiene alguna web vinculada. Resumiendo: no tenemos en cuenta la web desarrollada, sino que predecimos el precio de venta de la URL. Para ello, comparamos el valor del dominio con el histórico de otros dominios vendidos en los que el precio de venta no incluía la venta de la web desarrollada.

### ¿Qué datos están incluidos en los planes de la API de dominios de GoDaddy?

La API de dominios de GoDaddy proporciona un conjunto sólido de funcionalidades que permiten a los usuarios gestionar e interactuar con nombres de dominio de manera eficiente.

1. **Búsqueda y compra de dominios**: los usuarios pueden buscar la disponibilidad de dominios y registrarlos. Admite búsquedas masivas, validación de contactos y recuperación de esquemas para TLD específicos.
2. **Gestión de dominios**: la API permite actualizar los detalles del dominio, como registros de DNS, contactos y configuraciones de privacidad. Los usuarios también pueden cancelar dominios, renovarlos y transferir dominios entre registradores, incluyendo la gestión de solicitudes de transferencia.
3. **Registros DNS**: permite la recuperación, adición, modificación y eliminación de registros DNS según el tipo y el nombre del dominio.
4. **Valoración de dominios**: los usuarios pueden valorar nombres de dominio y obtener el precio de lista sugerido y su probabilidad de venta.

### ¿Cómo puedo empezar a utilizar la API de dominios de GoDaddy?

Comenzar a utilizar la API de dominios de GoDaddy es rápido y sencillo. Obtén todos los detalles para acceder y utilizar las API de GoDaddy en nuestra útil [documentación de introducción](https://developer.godaddy.com/getstarted).

### ¿Cómo puedo aumentar los límites de mi API?

Si necesitas más llamadas, puedes adquirir y acumular los planes adicionales Básico o Empresarial para alcanzar tus valoraciones diarias deseadas o el límite de llamadas mensual.

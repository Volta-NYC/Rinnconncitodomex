## Perguntas frequentes sobre Avaliação de domínios

### O que constitui um excelente domínio?

A resposta mais simples é: muita coisa. É fácil de memorizar? É constituído por uma palavra ou doze? É uma palavra ou expressão popular? E estes são apenas alguns fatores.

### O que é a Avaliação de domínio?

GoDaddy As Avaliações de domínio utilizam a aprendizagem de máquina para prever com precisão o valor de um nome de domínio. Servindo-nos de grandes volumes de dados e da atomização de palavras, criámos um modelo capaz de avaliar o valor de um domínio. Em termos simples, a ferramenta de valorização de domínios remove muita da adivinhação no que respeita a prever o valor do seu domínio. Visto que a nossa avaliação de domínio é executada de uma forma mais eficiente por se centrar nas palavras exatas de um domínio, é importante considerar a inclusão de termos de SEO essenciais ao selecionar um nome de domínio.

### A GoDaddy avalia domínios que pertencem a outras entidades registadoras?

A GoDaddy pode avaliar nomes de domínio de qualquer outra entidade registadora, mas oferecemos a melhor precisão em domínios comuns baseados em língua inglesa.

### A GoDaddy avaliará todo o meu portefólio de domínios?

Sim, a GoDaddy virá a ter recursos para avaliar portefólios inteiros de domínios. Quando tiver um nome de domínio valioso que deve renovar ou proteger, iremos informá-lo através de Os meus domínios e da sua conta GoDaddy.

### A GoDaddy fornece avaliações de domínio para sites Web desenvolvidos?

A GoDaddy não avalia sites Web desenvolvidos, mas podemos fornecer uma avaliação de qualquer domínio, independentemente de haver qualquer site Web associado ao mesmo. Em suma, não temos em conta o site web desenvolvido, apenas prevemos o preço de venda do URL. Para tal, comparamos o valor do domínio com outros domínios históricos vendidos, em que o preço de venda não incluía o preço do site web desenvolvido.

### Que dados estão incluídos nos planos da API de Domínios GoDaddy?

A API de Domínios GoDaddy fornece um conjunto robusto de funcionalidades, permitindo aos utilizadores gerir e interagir com nomes de domínio eficientes.

1. **Pesquisa e compra de domínios**: os utilizadores podem procurar a disponibilidade de um domínio e registar domínios. Permite pesquisas em massa, validação de contactos e obtenção de esquemas para TLD específicos.
2. **Gestão de domínios**: a API permite atualizar as informações dos domínios, como registos de DNS, contactos e definições de privacidade. Os utilizadores também podem cancelar, renovar e transferir domínios entre entidades registadoras, o que abrange a gestão de pedidos de transferência.
3. **Registos de DNS**: permite a obtenção, a adição, a modificação e a eliminação de registos de DNS com base no nome e tipo de domínio.
4. **Avaliação de domínios**: os utilizadores podem obter a avaliação de nomes de domínio, obter um preçário sugerido e conhecer a probabilidade de venda.

### Como faço para começar a utilizar a API de Domínios GoDaddy?

Começar a utilizar a API de Domínios GoDaddy é rápido e fácil. Obtenha todas as informações para o acesso e utilização das API GoDaddy na nossa prática [Documentação de introdução](https://developer.godaddy.com/getstarted).
